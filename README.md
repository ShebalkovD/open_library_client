# Описание

Веб-приложение на чистом JS

# Функционал

- Поиск книг по запросу
- Оптимизация запросов (кэширование ответов сервера до перезагрузки страницы, таймаут после каждого запроса)

# Запуск приложения

Для запуска потребуется простой веб-сервер. Поместите файлы в папку, из которой раздается статика на сервере.
